# 🚀 Intervexa — AI-Powered Interview Copilot

Intervexa is a real-time AI interview assistant built to enhance virtual interview experiences with live transcription, intelligent response analysis, resume verification, and smart follow-up generation. 
Designed for platforms like Google Meet and Zoom, Intervexa combines multiple AI-powered backend services with a modern browser extension to deliver seamless interview assistance in real time.

## ✨ Features

* 🎙️ Real-time speech transcription using Whisper + Groq
* 🧠 AI-powered interview analysis and response assistance
* 📄 Resume parsing with vector embeddings
* ⚠️ Resume contradiction detection
* 💡 Intelligent follow-up question suggestions
* 🌐 Browser extension support for Google Meet & Zoom
* ⚡ High-fidelity mixed audio pipeline
* 🔥 Fast microservice-based architecture

## 🛠️ Tech Stack

* Python (FastAPI)
* React + WXT
* Whisper AI
* Groq API
* Vector Embeddings
* Node.js

## 📦 Architecture

Intervexa is split into multiple services:

* **SSI-Service** → Real-time transcription
* **Resume Parser** → Resume embedding generation
* **AI-Intelligence** → Analysis and contradiction detection
* **Interview Copilot Extension** → Frontend browser extension

## 🚀 Goal

Intervexa aims to redefine technical and professional interviews by providing an intelligent AI copilot capable of assisting, analyzing, and enhancing communication during live interview sessions.
